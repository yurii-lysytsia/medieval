# Стратегічна мапа

Статична MVP-мапа визначена в `MVPConfiguration.json` як `StaticHexMap`: її межі,
axial-координати, гекси та явні сусідства належать даним сценарію, а не SpriteKit.

SpriteKit лише відображає ці дані: гекси, міста й армії — окремі шари. Вибраний гекс
зберігається як UI-стан і не змінює `GameState`.

Керування: натисніть гекс для інспектора, перетягуйте для панорамування, використовуйте
коліщатко або pinch для масштабу й кнопку «Огляд мапи» для повернення до початкового виду.

Масштаб тримається точки під курсором — те, на що ви дивитесь, лишається на місці.
Камера обмежена межами мапи, тож порожня область поза картою на екран не потрапляє.

Річка зберігається як `RiverBoundary` між двома сусідніми гексами, а не як окремий гекс.
Вона визначається однаково з обох напрямків переходу. Під час атаки через таку межу
оборонцеві надається +1 до захисту; без перетину річки бонус не застосовується.
