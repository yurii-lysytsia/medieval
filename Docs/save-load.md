# Збереження та завантаження 0.6.0

Medieval зберігає повний стан локальної партії у версіонованому JSON-файлі з розширенням `.medievalsave`. Файл містить стан правил, світ, економіку, вибраний гекс і метадані для каталогу.

Збереження розташовані у стандартному каталозі macOS `Application Support/Medieval/Saves`. Атомарний запис захищає попередню версію файла від перерваного запису. Пошкоджені або несумісні файли не потрапляють до списку й не зупиняють застосунок.

Ручне керування доступне з головного меню та панелі гри:

- створення іменованого слота;
- перегляд дати, гравців і номера ходу;
- завантаження повного стану;
- видалення після обов’язкового підтвердження.

Окремий слот автозбереження оновлюється у фоновому actor після ключових дій. Після запуску гра пропонує продовжити незавершену партію. Відмова не видаляє автозбереження й не впливає на ручні слоти.
