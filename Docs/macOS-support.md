# Підтримка macOS

## Діапазон

Підтримуються поточний реліз macOS і два попередні: macOS 14, 15 та 26.
Мінімальна версія розгортання у проєкті — **macOS 14.0 (Sonoma)**.

## Матриця перевірки

| macOS | Перевірка збірки | Перевірка меню й сцени |
| --- | --- | --- |
| 14 Sonoma | Автоматична збірка з ціллю 14.0 | Потрібен ручний smoke-test на Mac з Sonoma |
| 15 Sequoia | Автоматична збірка з ціллю 15.0 | Потрібен ручний smoke-test на Mac з Sequoia |
| 26 Tahoe | Автоматична збірка з поточною ціллю SDK | Потрібен ручний smoke-test на Mac з Tahoe |

## Автоматична сумісність

Запустіть з кореня репозиторію:

```sh
./Scripts/verify-supported-macos.sh
```

Скрипт компілює застосунок для кожної цільової мінімальної версії. Він не
замінює запуск на відповідній версії macOS.

## Ручний smoke-test

На кожній цільовій версії macOS:

1. Відкрийте `Medieval.xcodeproj` у Xcode та запустіть схему `Medieval`.
2. Переконайтеся, що з’явилося головне меню.
3. Натисніть «Нова гра» та переконайтеся, що відкрилася ігрова SpriteKit-сцена.
4. Натисніть «Завершити хід» і перевірте зміну активного гравця.
