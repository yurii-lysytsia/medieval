# Hex-асети мапи

Каталог згенеровано з `Source/map.png` командою:

```sh
python3 Scripts/extract_hex_tiles.py Medieval/Assets/MapHexes/Source/map.png Medieval/Assets/MapHexes
```

- `tiles/` — 1200 окремих PNG із прозорим тлом, названих за рядком і колонкою.
- `terrain/` — по одному готовому представнику кожного розпізнаного типу місцевості.
- `hex-map.json` — координати odd-r/axial, шлях до PNG, ландшафт і ознака обрізання джерелом.

Нативний розмір спрайта — 39×43 px. Центри сусідніх гексів розташовані з кроком 36.5 px по горизонталі та 30 px по вертикалі; непарні рядки зміщені праворуч на 18.25 px.

Крайні верхній і нижній рядки частково обрізані оригінальним зображенням. Це явно позначено полем `isClippedBySource`; прозоре доповнення зберігає правильний розмір усіх спрайтів.
